# Smart Gram: Rural Livelihoods & Farmer Empowerment Platform

An integrated open-source digital platform designed to connect rural farmers and Self-Help Groups (SHGs) directly with buyers, eliminating middlemen and improving market linkage.

## Features
- **Direct-to-Consumer (D2C) Marketplace:** Direct trade between farmers/SHGs and buyers.
- **Multilingual Support:** Local language interface for rural users.
- **Real-Time Mandi Rates:** Transparent price tracking across regional markets.
- **Logistics & Storage Tracking:** Shared transportation and localized storage updates.

## Tech Stack
- **Frontend:** Flutter / React.js
- **Backend:** Node.js (Express)
- **Database:** PostgreSQL
- **Cloud/Hosting:** Firebase / AWS
